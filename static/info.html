Info, Requirements, Prizes

Requirements

  1. Build a CRUD app using Node.js and Express. Users should be able to create, read, update, and delete content = CRUD.

  2. Your app must relate to the word “express”—your voice; your style and aesthetic; the experiences that you would like to share; something you want to say to the world <3

  3. You must use the HackaTime extension for time tracking, share your experience building this app in the #athena-award channel.


Who?

This YSWS is for participants of the Athena Award. It’s a great beginner project if you're looking to start learning backend development.



What is Backend Development?

Backend development refers to coding the server-side of an application. In contrast, frontend development focuses on the client-side, which users interact with directly in their browsers.

Wrtiting backend code allows you to do stuff with databases, run websites and all those fun things!



What?

For this YSWS, you're going to build a backend (CRUD) application using Node.js and Express that fits the theme "express"— to communicate clearly, operating at high speed, a programing API, to squeeze out a scent
